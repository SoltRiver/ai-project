# Frontend Accessibility (SSR-first)

## Purpose
SSR + htmx 前提のアクセシビリティ最低基準。

## Checklist
- [ ] label と input の関連
- [ ] 見出し階層（h1→h2→...）
- [ ] キーボード操作（Tab/Enter/Esc）
- [ ] コントラスト
- [ ] アイコンボタンの aria-label
- [ ] htmx 更新後のフォーカス（迷子防止）

## Minimal JS Notes
- ESC でモーダルを閉じる
- 閉じたらトリガーへフォーカス復帰

## Codex Gate（推奨）
a11y 指針がテンプレ/実装に反映されているか Codex CLI でレビューする。
