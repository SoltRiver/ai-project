# Finalize Patch Prompt

目的：
レビュー後の最終パッチを確定させ、提出物を「そのままマージ可能」にします。

---

## Required Steps（必須手順）
1. 指摘点の反映（人間/AIレビュー）
2. **Codex CLI でレビューを実行**（/review または codex exec）
3. Codex 指摘のうち重要度 High は原則対応（見送りは理由必須）
4. 利用可能なテスト/チェックを実行（ある場合）
5. **対象ブランチにコミット & プッシュ**（修正完了時の確定作業）
6. 最終 diff + チェックリスト + 残リスクを提出

---

## Output Format（厳格）
1. 修正内容まとめ（箇条書き）
2. Codex Review Report（重要度順 + 対応結果）
3. Verification（テスト/手動確認）
4. Git Commit & Push（コミットメッセージ、ブランチ、push結果、CI）
5. 適用 diff（必要なら）
6. 動作確認項目
7. 残課題（あれば）

---

## ルール
- 指摘点はすべて扱う（反映 or 見送り理由）
- 余計な改善を足さない（差分最小）
- Tech Stack を破らない（SPA/JSライブラリ禁止）
