## 2. タブ仕様（基本編 / 応用編）— ローソク足パターン一覧

本セクションは **タブ（基本編/応用編）の仕様のみ** をまとめたものです。  
実装技術セット：**FastAPI + Jinja + htmx**（CSSは制約なし）

### 2.1 目的
- 一覧ページで「単体ローソク（基本編）」と「複数ローソク（応用編）」を **タブで切り替える**
- 切替は **ページ全体遷移ではなく、一覧部分のみを差し替える（htmx）**
- 選択中タブが視覚的に分かる（背景/文字色）
- タブはスクロールしても上部に残る（sticky）
- 固定時に **影（shadow）** を出す

### 2.2 UI仕様

#### 2.2.1 タブ種類
- タブは2つ固定
  - **単体ローソク（基本編）**
  - **複数ローソク（応用編）**

#### 2.2.2 タブ内の件数表示（バッジ）
- 各タブの右側に件数バッジを表示（例：`5` / `9`）
- 仕様（視覚）
  - 角丸（pill）
  - 文字は読みやすいサイズ（例：12px〜13px）
  - 選択タブでも非選択タブでも **常時表示**
- 仕様（データ）
  - 件数は**固定値として保持**し、パターン追加/削除時に手動更新する
  - 現在値：`basic=5` / `advanced=9`
- 仕様（挙動）
  - 初回描画時とタブ切替時に **数値カウントアップアニメーション**（0→目的値）
  - 目安：300〜600ms程度（過度に長くしない）

#### 2.2.3 選択状態の表現
- 選択中タブ：背景色/文字色を変更し、はっきり分かる状態にする
- 非選択タブ：通常状態（枠線あり）
- ホバー：軽い変化（例：背景を薄く）
- **アクセシビリティ配慮**
  - 赤/緑はローソク足図の色に使うため、タブ自体の配色は赤/緑を避ける
  - 色だけに依存しない（例：太字/下線/枠強調など）

#### 2.2.4 上部固定（sticky）+ 影
- タブ領域はスクロールしても上部に残る
- 固定状態のときに薄い影を付与して、コンテンツと分離が分かるようにする
- 影は強すぎない（例：y方向8〜16px、透明度低め）

### 2.3 情報設計 / テンプレ分割（Jinja）

#### 2.3.1 テンプレ構成（タブ関連のみ）
- `index.html`
  - `_tabs.html` を読み込む
  - 一覧差し替え領域 `#listArea` を配置
- `_tabs.html`
  - タブUI（2タブ + 件数バッジ）
  - `hx-get` による一覧差し替えのトリガーを持つ
- `_list_area.html`
  - タブ選択に応じた一覧（sections/cards）を描画
  - **htmxのswap target** になる

### 2.4 htmx 仕様（一覧差し替え）

#### 2.4.1 差し替え対象
- 差し替えるのは **一覧領域のみ**
  - 例：`<div id="listArea"> ... </div>`
- タブUI（tabs自体）は差し替えなくてよい（必要ならサーバ側でactive状態を返す設計も可）

#### 2.4.2 トリガー（タブクリック）
- タブボタン/リンクに以下を付与（例）
  - `hx-get="/candle-patterns?tab=basic"`
  - `hx-get="/candle-patterns?tab=advanced"`
  - `hx-target="#listArea"`
  - `hx-swap="innerHTML"`（または `outerHTML`：設計に合わせる）
  - `hx-push-url="true"`（推奨：URLに選択状態を反映）
  - `hx-indicator="#listLoading"`（読み込み中表示）

#### 2.4.3 URL（状態保持）
- クエリパラメータで状態を表現
  - `?tab=basic`
  - `?tab=advanced`
- 初期表示のデフォルト
  - パラメータ未指定時は `basic` とする

#### 2.4.4 読み込み中表示
- タブ切替中、一覧領域上部に「読み込み中…」等を表示（`aria-live="polite"` 推奨）
- 表示は控えめに（ページの邪魔にならない）

### 2.5 アクセシビリティ要件
- タブ領域：`role="tablist"`
- 各タブ：`role="tab"`
- 選択状態：`aria-selected="true/false"`
- キーボード操作（最低限）
  - Tabキーでタブにフォーカスできる
  - Enter/Spaceで切替できる（button要素推奨）
- 読み込み中の表示：`aria-live="polite"`

### 2.6 実装メモ（推奨）
- タブの選択状態は、**サーバ側（Jinja）で `tab` に応じて active class を付与**する
- `hx-push-url="true"` を使う場合、ブラウザの戻る/進むで状態が戻る挙動を確認する
- 件数バッジのカウントアップは軽量なJSでOK（外部ライブラリ不要）

### 2.7 受け入れ条件（Doneの定義）
- [ ] タブ2種類が表示される（基本編/応用編）
- [ ] クリックで **一覧領域のみ** が差し替わる（ページ全体はリロードしない）
- [ ] 選択タブが見た目で明確（背景/文字/枠など）
- [ ] タブはスクロールしても上部に残る（sticky）
- [ ] 固定状態で影が出る
- [ ] 件数バッジが表示され、切替時にカウントアップする
- [ ] 件数バッジは固定値（basic/advanced）で表示される
- [ ] ARIAが付与され、Tabキーで操作できる

## 4. カードUI仕様
- カードは縦積みレイアウト（タイトル → 画像 → 情報 → ボタン）
- hover時にカードが軽く浮く
- 3列グリッドで表示し、行に3枚未満の場合もカード幅は固定（右側は空白のまま）
- 画面幅に応じて2列 / 1列に切り替える

### カード内構成（一覧）
1. 名称
2. ローソク足画像（中央・ボックス内）
3. 特徴
   - リード文を太字、補足文は小さめで改行
   - 本文はインデントでタイトルと区別
4. ひと言メモ
   - 特徴が2行以上でも**メモの位置が揃う**ように余白を確保
5. 詳細を見るボタン（カード下部中央）

## 5. モーダル仕様
### 表示内容
- SVG画像（大）
- 名称・一言キャッチ
- 特徴（太字のリード + 補足テキスト）
- 詳細説明
- 出やすい場面
- 図の見方（1行）
- 注意点（箇条書き）

### 挙動
- モーダル内容は詳細ボタンの data-* からJSで反映（htmx差し替えは使わない）

### 閉じ込め防止
- 右上×ボタン
- overlayクリック
- ESCキー
- 閉じたら元ボタンへフォーカス復帰

## 13. Jinjaテンプレ構成（index / tabs / list）

本プロジェクトは **FastAPI + Jinja2 + htmx** のみで実装します（SPA/React等は不使用）。
テンプレは「一覧ページ（index）」「タブ（tabs）」「一覧領域（list）」に分割し、
モーダルは **index.html に常駐**させ、**詳細はJSで反映**します。

### 13.1 テンプレファイル構成（推奨）
```
templates/
  base.html
  candle_patterns/
    index.html                          # 一覧ページ + タブ + モーダル + 読み込み表示
    partials/
      _tabs.html                        # タブ（基本編/応用編 + 件数）
      _list_area.html                   # 一覧セクション + カード（htmx差し替え）
```

### 13.2 一覧ページ：templates/candle_patterns/index.html（役割）
- ページタイトル・ヒーローを表示
- タブUIを表示（sticky＋影、件数バッジのカウントアップ）
- `#listLoading` と `#listArea` を配置し、`_list_area.html` を読み込む
- モーダル外枠を常駐させ、詳細はJSで差し替える

### 13.3 タブ：templates/candle_patterns/partials/_tabs.html（役割）
- `role="tablist"` / `role="tab"` / `aria-selected` を付与
- `hx-get` で `#listArea` を差し替えるトリガー
- 件数は `group_counts` を表示

### 13.4 一覧領域：templates/candle_patterns/partials/_list_area.html（役割）
- カテゴリ見出しは `section-head` のpill + 件数
- `pattern-card-grid` は3列（レスポンシブで2列/1列）
- カードは 名称 / 画像 / 特徴 / ひと言メモ / ボタン

### 13.5 モーダル
- 外枠は `index.html` に常駐
- 詳細ボタンの `data-*` をJSで反映
- 閉じ方は ESC / overlay / ×

### 13.6 画面仕様との対応表
- **タブ**：`templates/candle_patterns/partials/_tabs.html`
- **一覧（セクション + カード）**：`templates/candle_patterns/partials/_list_area.html`
- **モーダル**：`templates/candle_patterns/index.html` + `static/js/app.js`
