## 2. タブ仕様（基本編 / 応用編）— ローソク足パターン一覧

本セクションは **タブ（基本編/応用編）の仕様のみ** をまとめたものです。  
実装技術セット：**FastAPI + Jinja + htmx**（CSSは制約なし）

### 2.1 目的
- 一覧ページで「単体ローソク（基本編）」と「複数ローソク（応用編）」を **タブで切り替える**
- 切替は **ページ全体遷移ではなく、一覧部分のみを差し替える（htmx）**
- 選択中タブが視覚的に分かる（背景/文字色）
- タブはスクロールしても上部に残る（sticky）
- 固定時に **影（shadow）** を出す

### 2.2 UI仕様

#### 2.2.1 タブ種類
- タブは2つ固定
  - **単体ローソク（基本編）**
  - **複数ローソク（応用編）**

#### 2.2.2 タブ内の件数表示（バッジ）
- 各タブの右側に件数バッジを表示（例：`3` / `9`）
- 仕様（視覚）
  - 角丸（pill）
  - 文字は読みやすいサイズ（例：12px〜13px）
  - 選択タブでも非選択タブでも **常時表示**
- 仕様（挙動）
  - 初回描画時とタブ切替時に **数値カウントアップアニメーション**（0→目的値）
  - 目安：300〜600ms程度（過度に長くしない）

#### 2.2.3 タブ補足文（タブ直下）
- タブの下に1行の補足文を表示
- 目的：切替の意味が視覚的に理解できるよう補足する
- 文例（調整可）
  - 「タブで **基本編 / 応用編** を切り替えできます（一覧のみ差し替え）」

#### 2.2.4 選択状態の表現
- 選択中タブ：背景色/文字色を変更し、はっきり分かる状態にする
- 非選択タブ：通常状態（枠線あり）
- ホバー：軽い変化（例：背景を薄く）
- **アクセシビリティ配慮**
  - 赤/緑はローソク足図の色に使うため、タブ自体の配色は赤/緑を避ける
  - 色だけに依存しない（例：太字/下線/枠強調など）

#### 2.2.5 上部固定（sticky）+ 影
- タブ領域はスクロールしても上部に残る
- 固定状態のときに薄い影を付与して、コンテンツと分離が分かるようにする
- 影は強すぎない（例：y方向8〜16px、透明度低め）

### 2.3 情報設計 / テンプレ分割（Jinja）

#### 2.3.1 テンプレ構成（タブ関連のみ）
- `index.html`
  - `_tabs.html` を読み込む
  - 一覧差し替え領域 `#listArea` を配置
- `_tabs.html`
  - タブUI（2タブ + 件数バッジ + 補足文）
  - `hx-get` による一覧差し替えのトリガーを持つ
- `_list_area.html`
  - タブ選択に応じた一覧（sections/cards）を描画
  - **htmxのswap target** になる

### 2.4 htmx 仕様（一覧差し替え）

#### 2.4.1 差し替え対象
- 差し替えるのは **一覧領域のみ**
  - 例：`<div id="listArea"> ... </div>`
- タブUI（tabs自体）は差し替えなくてよい（必要ならサーバ側でactive状態を返す設計も可）

#### 2.4.2 トリガー（タブクリック）
- タブボタン/リンクに以下を付与（例）
  - `hx-get="/candle-patterns?tab=basic"`
  - `hx-get="/candle-patterns?tab=advanced"`
  - `hx-target="#listArea"`
  - `hx-swap="innerHTML"`（または `outerHTML`：設計に合わせる）
  - `hx-push-url="true"`（推奨：URLに選択状態を反映）
  - `hx-indicator="#listLoading"`（読み込み中表示）

#### 2.4.3 URL（状態保持）
- クエリパラメータで状態を表現
  - `?tab=basic`
  - `?tab=advanced`
- 初期表示のデフォルト
  - パラメータ未指定時は `basic` とする

#### 2.4.4 読み込み中表示
- タブ切替中、一覧領域上部に「読み込み中…」等を表示（`aria-live="polite"` 推奨）
- 表示は控えめに（ページの邪魔にならない）

### 2.5 アクセシビリティ要件
- タブ領域：`role="tablist"`
- 各タブ：`role="tab"`
- 選択状態：`aria-selected="true/false"`
- キーボード操作（最低限）
  - Tabキーでタブにフォーカスできる
  - Enter/Spaceで切替できる（button要素推奨）
- 読み込み中の表示：`aria-live="polite"`

### 2.6 実装メモ（推奨）
- タブの選択状態は、**サーバ側（Jinja）で `tab` に応じて active class を付与**する
- `hx-push-url="true"` を使う場合、ブラウザの戻る/進むで状態が戻る挙動を確認する
- 件数バッジのカウントアップは軽量なJSでOK（外部ライブラリ不要）

### 2.7 受け入れ条件（Doneの定義）
- [ ] タブ2種類が表示される（基本編/応用編）
- [ ] クリックで **一覧領域のみ** が差し替わる（ページ全体はリロードしない）
- [ ] 選択タブが見た目で明確（背景/文字/枠など）
- [ ] タブはスクロールしても上部に残る（sticky）
- [ ] 固定状態で影が出る
- [ ] 件数バッジが表示され、切替時にカウントアップする
- [ ] 補足文がタブ直下に表示される
- [ ] ARIAが付与され、Tabキーで操作できる

## 12. Jinjaテンプレ構成（index / section / card）

本プロジェクトは **FastAPI + Jinja2 + htmx** のみで実装します（SPA/React等は不使用）。
テンプレは「一覧ページ（index）」「カテゴリセクション（section）」「カード（card）」に分割し、
モーダルは **外枠（shell）を常駐**させ、**中身（content）をhtmxで差し替え**ます。

### 12.1 テンプレファイル構成（推奨）
```
templates/
  layout/
    base.html
  pages/
    candle_patterns/index.html          # 一覧ページ（タブ＋セクション＋カード）
  partials/
    candle_patterns/
      _tabs.html                        # タブ（基本編/応用編）
      _section.html                     # セクション（陽線/陰線/迷い + 件数）
      _card.html                        # カード（一覧：説明＋一言キャッチ）
      _modal_shell.html                 # モーダル外枠（常駐）
      _modal_content.html               # モーダル中身（htmxで差し替え）
```

### 12.2 一覧ページ：pages/candle_patterns/index.html（役割）
- ページタイトル・補足文を表示
- タブ（基本編/応用編）を表示（sticky＋影、件数バッジのカウントアップ）
- 3カテゴリ（陽線/陰線/迷い）を **セクション分け**してカードをグリッド表示
- モーダル外枠（shell）をページ末尾に常駐配置

**テンプレ呼び出しイメージ（擬似）**
```
{% extends "layout/base.html" %}
{% block content %}
  {% include "partials/candle_patterns/_tabs.html" %}

  {% for section in sections %}
    {% include "partials/candle_patterns/_section.html" %}
  {% endfor %}

  {% include "partials/candle_patterns/_modal_shell.html" %}
{% endblock %}
```

### 12.3 セクション：partials/candle_patterns/_section.html（役割）
- セクション見出しを画像のように表示
  - 例：`陽線（上向き）` の色付きラベル + `3件` バッジ
- その下にカードを **3列グリッド** で並べる
- 見出しとカードの余白を確保し「カテゴリタイトルが無いように見える」問題を回避する

**入出力（Jinjaコンテキスト）**
- 入力：`section = { key, title, count, items[] }`
- 出力：見出し＋カード一覧

### 12.4 カード：partials/candle_patterns/_card.html（一覧用）
一覧カードは **高さ固定（情報量に関係なく揃える）**。
一覧で表示する要素は **「説明」「一言キャッチ」** のみ。  
（「出現しやすい場面」「図の見方」はモーダル側のみ表示）

**カード内レイアウト（確定）**
- 上から順に：
  1) 名称  
  2) ローソク足画像（中央、大きめ）  
  3) 説明（見出し＋区切り線＋本文）  
  4) 一言キャッチ（見出し＋区切り線＋本文）  
  5) 詳細を見るボタン（カード下部中央）  
- 区切り線（横線）は **カード内に必ず存在**させる
- hover時にカードが軽く浮く
- 「詳細を見る」クリックで htmx でモーダル内容を取得して表示

**入出力（Jinjaコンテキスト）**
- 入力：`item = { id, name, desc, catch, svg }`
- 出力：カード1枚

### 12.5 モーダル：partials/candle_patterns/_modal_shell.html / _modal_content.html
- shell（外枠）は常駐（`#patternModal`）
- content（中身）は `hx-get` で取得し `#patternModalContent` を差し替え

**モーダル中身（content）で表示する項目**
- SVG画像（大）
- 名称・一言キャッチ
- 図の見方（どこを見るか）1行
- 詳細説明
- 注意点（箇条書き）

**閉じ込め防止（必須）**
- 右上×、overlayクリック、ESCキーで閉じる
- 閉じたら「詳細を見る」ボタンへフォーカス復帰

### 12.6 画面仕様とテンプレの対応表（要点）
- **タブ**：`_tabs.html`（sticky＋影、件数バッジのカウントアップ）
- **カテゴリ見出し**：`_section.html`（色付きラベル＋件数）
- **カード（一覧）**：`_card.html`（説明＋一言キャッチのみ、固定高さ）
- **モーダル**：`_modal_shell.html` + `_modal_content.html`（場面＋見方＋詳細＋注意点）

## 13. Codex依頼時の指示（追加）
- 本仕様書の「12. Jinjaテンプレ構成」に沿って、テンプレを **index / section / card** に分割して実装すること。
- モーダルは shell 常駐 + content 差し替え（htmx）で実装すること。
- 一覧カードは高さ固定で、表示は「説明」「一言キャッチ」のみにすること。
- 「出現しやすい場面」「図の見方」はモーダル内に表示すること。
- 文字コードはUTF-8前提で実装・表示すること。
- 仕様書（ドキュメント）は人が読みやすい表現を優先しつつ、実装者（生成AI含む）が参照しやすい構造で記述すること。
