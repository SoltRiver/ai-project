# 株価分析アプリ 要件（FastAPI + htmx）

## プロジェクトルール（Tech Stack）
- 使用する技術は FastAPI / Jinja2 テンプレート / htmx のみ。
- React, Vue, Svelte, Next.js などの SPA フレームワークやビルドツールは導入しない。
- JavaScript は必要最低限のプレーン JS（例: ESCでモーダルを閉じる、フォーカス復帰、カウントアップ）だけを許可。ライブラリは使わない。
- サーバーレンダリング + htmx の部分更新を優先する。
- 文字コードは UTF-8 で統一する。

---

## 共通仕様
1. 銘柄名（銘柄コード）は全画面で日本語表記に統一する。API が英語を返す場合は日本語に変換して表示する。例: トヨタ自動車（7203）
2. 現在値・最高値・最安値は小数第1位まで表示する（例: ¥3,305.1）。
3. 現在値・変動額（変動率）の配色ルールを統一（プラス=緑、マイナス=赤、ゼロ=グレー）。ヒートマップと同じ配色にする。
4. 株価リストで使っている「↑/↓ の上下アニメーション」を株価情報詳細画面を含む全画面で適用する。

---

## 株価リスト画面（/stocks）
1. 「銘柄に関する情報のみを4列で表示します。」の文言を削除する。
2. 一括削除ボタンの表記を「削除」に変更し、赤系 (#e53e3e 目安) で強調する。
3. 最高値・最安値は小数点以下を切り捨てて整数表示する（リスト画面のみの例外。他画面は小数第1位表示）。
4. 株価リスト右上に更新時刻を表示する（例: （2025/01/05 14:30 時点））。フォントサイズは本文より小さめ（0.8rem 程度）。
5. 銘柄名（銘柄コード）左のチェックボックス列のタイトルを「削除フラグ」にする。

---

## 株価情報詳細画面（/stocks/{code}）
1. 画面タイトルを「株価情報詳細」に統一する。
2. ローソク足チャートが正しく表示されるようにデータ取得・整形・描画を修正する。
3. 画面上部の情報表示順を以下に統一する：  
   - 銘柄名（コード）  
   - 現在値（¥、大きめフォント）  
   - 変動額（整数、¥付き、現在値より少し小さめ）  
   - 変動率（% 小数第2位、変動額の横に括弧付き）  
   - 色分け：プラス＝緑、マイナス＝赤、ゼロ＝グレー
4. ローソク足チャートに足種を追加し、ドロップダウンで選択可能にする：1分足 / 5分足 / 10分足 / 日足 / 週足 / 月足。
5. チャートはリアルタイム更新（polling または WebSocket）に対応させる。
6. 以下の画面内固定表示セクションを削除する：ローソク足ポップアップ欄、サポート/レジスタンス欄、ローソク足パターン欄、最新足サマリー欄。
7. チャートのホバー時ツールチップに以下を表示する：始値・高値・安値・終値（各¥小数第1位）、出来高、ローソク足パターン。サポート/レジスタンスが該当価格帯にある場合は価格と簡易説明を追加表示。
8. チャート内に支持線・抵抗線を自動描画し、該当ローソク足をホバーした場合に値と説明をポップアップに追加する。
9. チャート下部に出来高バーを表示し、足種に応じて目盛りなどが変化するようにする。
10. 縦軸（株価）は小数第1位、横軸（時間）は足種に応じて HH:mm または yyyy/mm/dd 形式で表示する。
11. タブ（チャート／ファンダメンタル分析／配当／株主優待）はアクセシビリティに配慮して以下を満たす：コントラスト比4.5:1以上、ボタン形状を明確化、表示中タブの視認性強化、hover時の色変化、必要に応じてアイコン追加。
12. 売買シグナルは初心者向けに分かりやすく表示する（ゴールデン・デッドクロス、RSIの買われすぎ/売られすぎ、MACDの方向性、支持線/抵抗線の位置＋短い解説文）。
13. リスク情報は初心者向けに要約して表示する（ボラティリティ、出来高の急変、悪材料ニュースの要約、決算前後の注意、優待や権利付き最終日の影響）。
14. 「プラス要素」項目を新設し、初心者向けに表示する（好材料ニュース要約、好決算・業績改善、増配/優待改善、業界全体の強さ、外部環境の追い風）。
