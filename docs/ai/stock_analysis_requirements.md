# 株価分析ツール 仕様・実装ルール（FastAPI + htmx ベース・最新版）

========================================
1. 技術スタック・全体方針
========================================
- バックエンド: FastAPI（Python）
- テンプレート: Jinja2Templates
- フロント: サーバーサイドレンダリング + htmx による部分更新
- JS フレームワーク（React/Vue 等）は使わない。必要最低限の JS のみ（htmx がメイン）。
- 既存の Python プロジェクト構成は尊重し、大きく壊さずに組み込む。

========================================
2. URL / 画面構成
========================================
■ 一覧系
- /stocks
  - 「株価リスト」を表示する画面。
  - 複数銘柄の概要をテーブル形式で表示。
  - 銘柄名リンクから銘柄ごとの「株価詳細情報」画面へ遷移。

■ 詳細系
- /stocks/{code}
  - 銘柄ごとの「株価詳細情報」画面。
  - 画面内にタブを持つ:
    - チャート
    - ファンダメンタル分析
    - 配当
    - 株主優待

- /stocks/{code}/tab/{tab_name}
  - 上記タブの中身だけを返す htmx 用エンドポイント。
  - tab_name:
    - "chart"
    - "fundamental"
    - "dividend"
    - "shareholder"

■ 用語系
- /glossary
  - 「用語辞典」画面。
  - 一般的な投資用語（PER, PBR, トレンドなど）を掲載。
- /candle-patterns
  - 「ローソク足パターン」画面。
  - 用語辞典から独立し、ローソク足パターンの解説を集約。

========================================
3. テンプレート構成ルール
========================================
テンプレートディレクトリ（例）:
- templates/
  - base.html                  : 全体レイアウト（ヘッダー・フッター・テーマ切替など）
  - stocks/
    - list.html                : /stocks（株価リスト）
    - detail.html              : /stocks/{code}（詳細コンテナ）
    - partials/
      - _tab_chart.html        : チャートタブ
      - _tab_fundamental.html  : ファンダメンタル分析タブ
      - _tab_dividend.html     : 配当タブ
      - _tab_shareholder.html  : 株主優待タブ
  - glossary/
    - glossary.html            : 用語辞典
  - candle_patterns/
    - index.html               : ローソク足パターン一覧・解説

ルール:
- base.html を全ページの共通レイアウトとする。
- list.html, detail.html は base.html を extends する。
- partials/_tab_xxx.html はレイアウトを継承せず、<div> から始める「部分テンプレート」とする。

========================================
4. htmx の使い方ルール
========================================
- htmx は base.html で読み込む（全画面共通）。
  例: <script src="/static/js/htmx.min.js"></script>
- タブ切替は htmx の hx-get / hx-target / hx-swap を使って実装する。
  - 各タブボタン:
    - hx-get="/stocks/{{ stock.code }}/tab/chart" など
    - hx-target="#tab-content"
    - hx-swap="innerHTML"
- 初期表示:
  - detail.html 内の #tab-content に対して
    - hx-get="/stocks/{{ stock.code }}/tab/chart"
    - hx-trigger="load"
  を設定し、読み込み時にチャートタブを自動ロード。

========================================
5. 株価リスト画面 (/stocks) の仕様
========================================
■ テーブル項目
- 株価リストには「銘柄に関する情報のみ」を表示する。
- 項目は以下 4 つに限定する:
  1. 銘柄名（銘柄コード）
  2. 現在値
  3. 変動額（変動率）
  4. 最高値／最安値

■ 行の例
- 1行目（ヘッダー、削除列は別仕様に応じて利用）
  - 削除 | 銘柄名（銘柄コード） | 現在値 | 変動額（変動率） | 最高値/最安値
- データ行の例:
  - □ | トヨタ自動車（7203） | ￥3,000.00 | -10円（-2.29%） ↓ | ￥3,050 / ￥2,980

■ 銘柄名リンク
- 「銘柄名（銘柄コード）」は必ずリンクとし、クリックで /stocks/{code} へ遷移:
  - 表示例: トヨタ自動車（7203）
  - href="/stocks/7203"

■ 変動額（変動率）の表示ルール
- 下落: 赤テキスト + 下向き矢印アイコン（↓）
- 上昇: 緑テキスト + 上向き矢印アイコン（↑）
- 変化なし: グレー（アイコンなし、または→）
- アイコン（↑↓）には CSS アニメーションで軽い上下動をつけ、リアルタイム変動感を出す。

■ その他
- 「追加 +」ボタンを株価リストの上部に配置し、新規銘柄を追加できるようにする（検索して追加）。
- 削除はチェックボックスの複数選択 → 一括削除ボタンで対応。

========================================
6. 株価詳細情報画面 (/stocks/{code}) 共通仕様
========================================
■ 概要
- タイトル付近に「銘柄名（銘柄コード）」を表示。
- 画面内に以下タブを配置:
  - チャート
  - ファンダメンタル分析
  - 配当
  - 株主優待
- 各タブクリックで htmx により #tab-content のみ差し替える。

■ 初心者向け表現
- 専門用語にはツールチップや用語辞典へのリンクを付ける。
- 難しい指標も一言コメントで「簡易解説」を表示（例：PER →「株価が利益の何倍かを表す指標です」）。

■ 共通で表示しうる情報（いずれかのタブ内 or サマリー）
- 直近イベント:
  - 次回決算日
  - 配当権利付き最終日
  - 配当利回り
  - 株主優待の有無
- 企業スコア（★ 1〜5）:
  - 安定性 / 成長性 / 割安度 / 配当魅力度 など
  - 各スコアの下に1行コメントを表示。

■ リスク表示
- ボラティリティ高: 「価格変動が大きめの銘柄です」と表示。
- 流動性低: 「売買が成立しにくい場合があります」と表示。

========================================
7. チャートタブ（_tab_chart.html）の仕様
========================================
■ 足種切り替え
- 「日足」「週足」「月足」を切り替え可能なボタン／トグルをチャート上部に配置。
- 期間切替（例: 1年 / 5年 / 10年）と足種切替は別コンポーネントで、組み合わせて表示可能。

■ ローソク足の描画
- 色:
  - 上昇ローソク足（陽線）：緑
  - 下落ローソク足（陰線）：赤
- ヒートマップ等の「上昇＝緑、下落＝赤」と配色を統一。

■ 移動平均線
- 表示する線は「短期線・中期線・長期線」の3本。
- 各線の候補:
  - 短期線: 5日 or 10日
  - 中期線: 50日 or 75日
  - 長期線: 100日 or 200日
- 各線ごとにプルダウンや設定 UI で日数を選択可能。
- 線色はチャート上で識別しやすいように（例: 短期=やや明るい色、中期/長期=別色）。

■ トレンドライン
- 自動判定したトレンドを表示:
  - 上昇トレンド（BULL）：橙色ライン
  - 下落トレンド（BEAR）：水色ライン
  - もみ合い（NEUTRAL）：グレーライン
- 表示の ON/OFF を切り替え可能。

■ 抵抗線・支持線
- 主な高値・安値に基づき、水平の抵抗線・支持線を自動描画。
- 可能ならドラッグで微調整できる。
- 別エリアに「直近サポート：￥○○○○」「レジスタンス：￥○○○○」などをテキスト表示し、
  初心者向けの説明を付ける。

■ チャートの目盛り
- 縦軸（価格）およびポップアップ表示は小数第2位まで表示（例: ￥3,021.35）。

■ ローソク足ポップアップ（ツールチップ）
- すべて日本語表記。
- 価格（始値・高値・安値・終値）は必ず「￥」付きで表示。
- 出来高などは日本語ラベルのみ（￥なし）。
- 「ローソク足パターン名」を含める（例: ローソク足パターン：大陽線）。
- 移動平均線の説明や値はポップアップから削除（別UIで表示する場合はあってもOK）。

■ 売買シグナル（初心者向け）
- ゴールデンクロス／デッドクロスなどのシグナルを簡潔に表示。
- RSIに基づき「売られすぎ」「買われすぎ」ステータスを表示。
- あくまで「参考情報」であり、投資判断の最終責任は利用者にある旨を注記。

========================================
8. ファンダメンタル分析タブ（_tab_fundamental.html）
========================================
■ 名称
- 「ファンダメンタル情報」ではなく「ファンダメンタル分析」で統一。

■ 指標表示
- PER, PBR などの基本指標を表示。
- 各指標の右側に「割安／割高／標準／優良」などの評価ラベルを追加。
  - プラス評価（割安・優良など）：緑
  - マイナス評価（割高・注意など）：赤
  - 中立（標準）：グレー
- ラベルの根拠はコメントで簡単に示す（例: 「業界平均より低めで割安傾向です」など）。

■ 売り時・買い時のタイミング
- 「売り時・買い時のタイミング」というセクションを追加。
- 短期／中期／長期の3つの時間軸ごとに、初心者にも分かる表現で目安を記載。
  - 例: 「短期: ○○円付近まで下落したら押し目買いを検討」「長期: ○年単位での保有を前提に、○○円以下は割安ゾーンとして検討」など。
- 価格やレンジは参考目安として示し、「必ずそう動くわけではない」旨を明記。

========================================
9. 配当タブ（_tab_dividend.html）
========================================
- 表示項目:
  - 配当年月日
  - 配当金
- 過去の配当履歴を一覧形式で表示できると望ましい。
- 合わせて、現在の配当利回りや配当方針（安定配当／増配傾向など）を簡潔に載せる。

========================================
10. 株主優待タブ（_tab_shareholder.html）
========================================
- 表示項目（例）:
  - 必要株数
  - 優待内容
  - 権利確定月
  - 注意事項（変更可能性など）
- 画像やアイコンを用いて、初心者にも分かりやすく表示する。

========================================
11. 用語辞典 / ローソク足パターン
========================================
■ 用語辞典 (/glossary)
- PER, PBR, 配当利回り, トレンド, ボラティリティ など一般用語を掲載。
- 各用語は短い説明＋初心者向け一言コメント。

■ ローソク足パターン (/candle-patterns)
- 用語辞典とは別ページとして独立。
- 大陽線／大陰線／カラカサ／トンボ／包み足／はらみ足 等、
  ローソク足パターンを図付きで解説。
- チャートパターンをグリッド表示し、各カードに解説を載せる。
- 図のラインは点線ではなく、直線または曲線で描画。

========================================
12. デザイン・テーマ・アクセシビリティ
========================================
■ テーマ
- ライトテーマ（背景: 白）
- ダークテーマ（背景: 黒系の落ち着いた色）
- テーマ切替は body または html にクラスを付与し、CSS 変数で制御。
- コントラスト比を十分に確保し、特にダークモードで文字が読みにくくならないよう注意。

■ 色の意味の統一
- 上昇: 緑
- 下落: 赤
- 中立／変化なし: グレー
- ヒートマップ、ローソク足、変動率表示など、全体で意味が揃うよう統一。

■ ラグジュアリーなデザイン
- 各セクションタイトルの横に意味の分かりやすいアイコンを追加。
  - チャート: グラフアイコン
  - ファンダメンタル分析: 書類/分析アイコン
  - 配当: コイン/円マークアイコン
  - 株主優待: ギフト/チケットアイコン
- 余白、フォント、カード風コンポーネントを用い、情報量は多くても「すっきり・高級感のある」見た目を目指す。
