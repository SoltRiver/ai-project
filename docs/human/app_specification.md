# 株価分析アプリ 仕様書

## 1. 概要
本アプリケーションは、初心者から中級者の投資家を対象とした、AIによる情報の要約と視覚的なデータ分析を提供する株価分析ツールです。
リアルタイムの市場データ、ニュース、財務指標（ファンダメンタルズ）、およびテクニカル分析（キャンドルパターン）を統合し、投資判断のサポートを行います。

## 2. 主要機能
### 2.1 銘柄管理（Stock List）
- **銘柄検索・追加**: 銘柄名またはコードによる検索。**j-Quants API** から上場銘柄マスターを取得し、前方一致検索とオートコンプリートを提供。ウォッチリストへの追加が可能。
- **リスト表示**: 登録銘柄の現在値、前日比、騰落率を一覧で確認。
- **チャート表示**: 各銘柄の株価推移を視覚化（移動平均線、ゴールデンクロス/デッドクロス表示）。
- **出来高分析**: 出来高バーをゴールド（#FFD700）で統一し、ツールチップで具体的な出来高（万株単位）を確認可能。

### 2.2 市場インデックス（Market Indices）
- 日経平均、TOPIX、NYダウ、NASDAQなどの国内外の主要指数のリアルタイム（または遅延）データの表示。

### 2.3 AIニュース（AI Market News）
- **ニュース収集**: Yahoo Finance等から主要な市場ニュースを自動取得。
- **AI和訳・要約**: 英語ニュースの自然な日本語訳と、3行程度の簡潔な要約の提供。
- **市場影響分析**: ニュースが個別銘柄やセクターに与える影響（Positive/Negative）をAIが判定。
- **原文確認**: 翻訳前のタイトルをツールチップ等で確認可能。

### 2.4 ファンダメンタルズ分析（Fundamental Analysis）
- **財務データ視覚化**: 売上高、営業利益、純利益、総資産、純資産の推移に加え、資産構成（純資産・負債）を円グラフで表示。
- **投資指標算出**: J-Quants API (株価データ) と EDINET (財務データ) を統合し、**j-Quants認証ユーザー向け**に PER (株価収益率), PBR (株価純資産倍率), ROE (自己資本利益率), EPS, BPS を自動算出・表示。
- **データソース (Hybrid)**: EDINET API v2 (XBRL) + J-Quants API (Daily Quotes/Listed Info)。
- **フォールバック機能**: 市場データ取得失敗時（または未認証時）でも、財務データのみを用いた分析レポートを表示可能。

### 2.5 テクニカル分析（Candle Patterns）
- **キャンドルパターン認識**: 全53種類のローソク足パターン（大陽線、包み足、はらみ足等）を自動検知して表示。
- **ツールチップ連携**: チャート上のパターン名をクリックすると、そのパターンの特徴や推奨アクションをカード形式のモーダルで即座に確認可能。
- **学習ガイド**: パターン一覧ページ（Basic/Advanced）で、各パターンの詳細な意味や投資戦略を解説。

### 2.6 ランキング（Ranking）
- **騰落率ランキング**: 日次・週次・月次の値上がり/値下がり率ランキングを表示。
- **AI市場解説**: ランキング上位銘柄の動きの背景や今後の展望をAIが分析してコメント。

### 2.7 用語集（Glossary）
- **ビジュアル解説**: 投資用語をカード形式で一覧表示。各用語に直感的なイメージ画像を配し、初心者でも理解しやすい構成。

### 2.8 EDINET書類検索（Document Search）
- **書類検索**: 日付指定および証券コードによる有価証券報告書等の検索機能。
- **分析連携**: 検索結果から直接ファンダメンタルズ分析レポート（2.4）へ遷移可能。

## 3. 技術スタック
本アプリは、シンプルかつ高性能なサーバーサイドレンダリング（SSR）構成を採用しています。

### 3.1 バックエンド
- **言語**: Python 3.11+
- **フレームワーク**: FastAPI
- **Webサーバー**: Uvicorn
- **テンプレートエンジン**: Jinja2

### 3.2 フロントエンド
- **マークアップ**: HTML5
- **スタイリング**: Vanilla CSS (ダークテーマ、レスポンシブデザイン)
- **スクリプト**: Vanilla JavaScript
- **動的更新**: htmx (ページ遷移なしの部分更新)
- **グラフ・描画**: 
  - **Custom Canvas Implementation**: 高速かつインタラクティブな株価・出来高チャート。
  - **Plotly.js**: 財務データ・資産構成の複雑なグラフ表示。

### 3.3 AI技術 (Hybrid Architecture)
- **Google Gemini API**: メインの分析エンジン。高速かつ高品質な和訳・要約に使用。
- **OpenAI API (GPT-4o mini)**: フェイルオーバー（代替）エンジン。Geminiの制限時に自動切り替え。

## 4. 外部API・データソース
| カテゴリ | サービス/API | 用途 |
| :--- | :--- | :--- |
| 市場データ | Yahoo Finance (yfinance) | 株価、指数、ニュースの取得 |
| 銘柄マスター | j-Quants API | 上場銘柄一覧、株価データ、発行済株式数の取得（ファンダメンタル分析用） |
| 財務情報 | EDINET API v2 (ZIP/XBRL) | 有価証券報告書の取得、財務数値抽出 |
| AI / 自然言語処理 | Google Gemini API | ニュース翻訳、要約、銘柄影響分析 |
| AI / 自然言語処理 | OpenAI API | ニュース分析のバックアップ |

## 5. 依存関係（主要ライブラリ）
`requirements.txt` に基づく主要な依存関係です。

- **Web関連**:
  - `fastapi`: APIフレームワーク
  - `uvicorn`: ASGIサーバー
  - `jinja2`: HTMLテンプレート
  - `htmx`: フロントエンド部分更新
- **データ分析**:
  - `pandas`: データ処理
  - `numpy`: 数値計算
  - `plotly`: インタラクティブなグラフ作成
- **金融・データ取得**:
  - `yfinance`: Yahoo Financeデータ取得
  - `edinet-xbrl`: EDINETデータパース
- **AI / その他**:
  - `google-generativeai`: Gemini APIクライアント
  - `openai`: OpenAI APIクライアント
  - `python-dotenv`: 環境変数管理
