# 株価分析アプリ 仕様書

## 1. 概要
本アプリケーションは、初心者から中級者の投資家を対象とした、AIによる情報の要約と視覚的なデータ分析を提供する株価分析ツールです。
リアルタイムの市場データ、ニュース、財務指標（ファンダメンタルズ）、およびテクニカル分析（キャンドルパターン）を統合し、投資判断のサポートを行います。

## 2. 主要機能
### 2.1 銘柄管理（Stock List）
- **銘柄検索・追加**: 銘柄名またはコードによる検索。**j-Quants API** から最新の上場銘柄マスターを取得し、前方一致検索とオートコンプリートを提供。ウォッチリストへの追加が可能。
- **リスト表示**: 登録銘柄の現在値、前日比を一覧で確認。
- **チャート表示**: 各銘柄の株価推移を視覚化。

### 2.2 市場インデックス（Market Indices）
- 日経平均、TOPIX、NYダウ、NASDAQなどの国内外の主要指数のリアルタイム（または遅延）データの表示。

### 2.3 AIニュース（AI Market News）
- **ニュース収集**: Yahoo Finance等から主要な市場ニュースを自動取得。
- **AI和訳・要約**: 英語ニュースの自然な日本語訳と、3行程度の簡潔な要約の提供。
- **市場影響分析**: ニュースが個別銘柄やセクターに与える影響（Positive/Negative）をAIが判定。
- **原文確認**: 翻訳前のタイトルをツールチップ等で確認可能。

### 2.4 ファンダメンタルズ分析（Fundamental Analysis）
- **財務データ視覚化**: 売上高、営業利益、純利益、ROE、自己資本比率などの推移をグラフ表示。
- **データソース**: EDINET（XBRL）から取得した公式な財務情報をベースに分析。

### 2.5 テクニカル分析（Candle Patterns）
- **キャンドルパターン認識**: 主要なローソク足パターン（包み足、はらみ足等）を自動検知して表示。
- **学習ガイド**: 各パターンの意味や投資戦略の解説を提供。

## 3. 技術スタック
本アプリは、シンプルかつ高性能なサーバーサイドレンダリング（SSR）構成を採用しています。

### 3.1 バックエンド
- **言語**: Python 3.11+
- **フレームワーク**: FastAPI
- **Webサーバー**: Uvicorn
- **テンプレートエンジン**: Jinja2

### 3.2 フロントエンド
- **マークアップ**: HTML5
- **スタイリング**: Vanilla CSS (ダークテーマ、レスポンシブデザイン)
- **スクリプト**: Vanilla JavaScript
- **動的更新**: htmx (ページ遷移なしの部分更新)
- **グラフライブラリ**: Plotly.js

### 3.3 AI技術 (Hybrid Architecture)
- **Google Gemini API**: メインの分析エンジン。高速かつ高品質な和訳・要約に使用。
- **OpenAI API (GPT-4o mini)**: フェイルオーバー（代替）エンジン。Geminiの制限時に自動切り替え。

## 4. 外部API・データソース
| カテゴリ | サービス/API | 用途 |
| :--- | :--- | :--- |
| 市場データ | Yahoo Finance (yfinance) | 株価、指数、ニュースの取得 |
| 銘柄マスター | j-Quants API | 上場銘柄一覧（コード・名称）の取得 |
| 財務情報 | EDINET API ( XBRL) | 決算情報の取得 |
| AI / 自然言語処理 | Google Gemini API | ニュース翻訳、要約、銘柄影響分析 |
| AI / 自然言語処理 | OpenAI API | ニュース分析のバックアップ |

## 5. 依存関係（主要ライブラリ）
`requirements.txt` に基づく主要な依存関係です。

- **Web関連**:
  - `fastapi`: APIフレームワーク
  - `uvicorn`: ASGIサーバー
  - `jinja2`: HTMLテンプレート
  - `htmx`: フロントエンド部分更新
- **データ分析**:
  - `pandas`: データ処理
  - `numpy`: 数値計算
  - `plotly`: インタラクティブなグラフ作成
- **金融・データ取得**:
  - `yfinance`: Yahoo Financeデータ取得
  - `edinet-xbrl`: EDINETデータパース
- **AI / その他**:
  - `google-generativeai`: Gemini APIクライアント
  - `openai`: OpenAI APIクライアント
  - `python-dotenv`: 環境変数管理
