# ローソク足パターン実装メモ（UTF-8）

- 実装方針: FastAPI + Jinja2 + htmx のサーバーレンダリングで一覧/モーダルを構成。JSは既存の最小限（モーダル表示・タブ切替・チャート描画）のみを使用。
- テンプレ構成: `templates/candle_patterns/index.html` の1ファイルに統合。タブ（基本編/応用編）、カテゴリ別カード（陽線/陰線/迷い）、モーダル外枠を常駐させ、カードのボタンクリックで中身を差し替え。
- カード表示: 「説明」「一言キャッチ」だけを固定高さで表示。SVGは右寄せ160px想定。hover時に浮かせるスタイルを `static/css/theme.css` で付与。
- モーダル表示: SVG大・名称/キャッチ・図の見方・詳細説明・注意点（箇条書き）を表示。ESC/overlay/×ボタンで閉じ、閉じたら元のボタンにフォーカスを戻す。
- データ源: `services/stock_service.py` の `CANDLE_PATTERN_CARDS` に全パターンを定義（基本3件、応用9件）。カテゴリは「陽線/陰線/迷い」、グループは「単体ローソク足（基本編）/複合ローソク足（応用編）」で件数バッジを表示。
- 文字コード: すべて UTF-8 で保存し、日本語テキストがそのまま読めるように整理。
