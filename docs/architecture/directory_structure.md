# ディレクトリ構成

本プロジェクトのディレクトリ構成ルールを以下に定めます。将来的な拡張やメンテナンスの指針としてください。

## ルートディレクトリ構成

```
ai-project/
├── data/          # 定数定義、辞書データ、静的なマッピング情報
├── docs/          # ドキュメント (Human/AI向け、設計資料など)
├── routers/       # FastAPIのルーター定義 (エンドポイント)
├── scripts/       # 運用・検証・デバッグ用のスクリプト
├── services/      # ビジネスロジック、外部API連携、データ取得処理
├── static/        # 静的ファイル (CSS, JS, 画像)
├── templates/     # Jinja2 テンプレート (HTML)
├── utils/         # 汎用ユーティリティ、計算ロジック
└── fastapi_app.py # アプリケーションエントリーポイント
```

## 各ディレクトリの詳細

### data/
アプリケーション内で使用される静的なデータや定数定義を配置します。
- `stock_name_mapper.py`: 銘柄コードと名称のマッピング
- `terms_data.py`: 用語集データ
- `candlestick_terms_data.py`: ローソク足パターン定義

### services/
アプリケーションのコアとなるビジネスロジックやデータ取得処理を配置します。
- `stock_service.py`: 株価情報の統合ロジック
- `data_fetcher.py`: yfinance 等からのデータ取得
- `jquants_client.py`: J-Quants API クライアント

### utils/
特定のドメインに依存しないライブラリ的な機能や、計算ロジックを配置します。
- `analyzer.py`: テクニカル分析指標の計算
- `candle_classify.py`: ローソク足の形状判定

### scripts/
開発中の検証や、定期実行が必要なスクリプト等を配置します。
- `regression_test.py`: 簡易リグレッションテスト
- `verify_*.py`: 各種機能の検証スクリプト

---
**注意**: 新規ファイルを追加する際は、適切なディレクトリに分類してください。ルートディレクトリへの直接配置は極力避けてください。
