# UIテスト ワークフロー

品質管理エージェント（`quality/ui_test.md` スキル）を使用して、UIの品質を体系的に検証します。

## 実行手順

1. **スキル読み込み**
   `.agent/skills/quality/ui_test.md` を読み込み、テスト観点を把握する。

2. **テスト対象の確認**
   変更があったページ/コンポーネントを特定する。変更がない場合は全ページを対象とする。
   // turbo

3. **Phase 1: 静的チェック**
   テンプレートHTML構造の整合性を確認する。
   // turbo

4. **Phase 2: ページ単位テスト**
   `browser_subagent` を使用して以下のページを順に検証する:
   - `/stocks` — レイアウト + 表示項目 + 操作
   - `/stocks/7203` — 全タブ切替 + コンテンツ表示
   - `/glossary` — カードレイアウト + 画像
   - `/candle-patterns` — パターンカード + 画像
   - `/indices` — 指数データ表示

5. **Phase 3: レスポンシブ + アクセシビリティ**
   主要ページをウィンドウサイズ変更（1920px / 768px / 375px）して確認する。

6. **Phase 4: パフォーマンス**
   ページ表示速度とhtmxタブ応答速度を簡易計測する。

7. **結果レポート**
   スキルの出力フォーマットに従い、サマリーテーブルとFAIL詳細を報告する。
   スクリーンショットを添付する。

## 判定基準
- **PASS**: 全カテゴリのFAILが0件
- **CONDITIONAL PASS**: FAILがLOW優先度のみ
- **FAIL**: HIGH優先度のFAILが1件以上
