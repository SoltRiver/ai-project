# パフォーマンステスト ワークフロー

品質管理エージェント（`quality/performance_test.md` スキル）を使用して、
アプリケーション全体のパフォーマンスを体系的に計測・分析します。

## 実行手順

1. **スキル読み込み**
   `.agent/skills/quality/performance_test.md` を読み込み、計測観点と閾値を把握する。

2. **Phase 1: 全体計測**
   `scripts/perf_check.py` を実行し、全エンドポイントの応答速度を取得する。
   // turbo

3. **閾値判定**
   スキルの閾値定義に基づき、各エンドポイントを PASS / WARNING / NG に分類する。

4. **Phase 2: ボトルネック分析**
   WARNING / NG のエンドポイントについて、原因を調査する。
   - DB クエリの N+1 / インデックス不足
   - 外部 API の直列呼び出し / タイムアウト
   - テンプレートの複雑度

5. **Phase 3: 静的資産チェック**
   CSS / JS / 画像のファイルサイズとキャッシュバスティング設定を確認する。
   // turbo

6. **Phase 4: チューニング提案**
   問題が検出された場合、スキルのチューニング指針に基づき改善案を作成する。
   - 優先度（HIGH / MID / LOW）を付与
   - 期待改善率と難易度を明記

7. **Phase 5: チューニング実施（承認後）**
   ユーザー承認を得た改善案を実施し、再計測で効果を確認する。

8. **結果レポート**
   スキルの出力フォーマットに従い、パフォーマンスサマリー・ボトルネック分析・チューニング提案を報告する。

## 判定基準
- **PASS**: 全エンドポイントが閾値以内
- **WARNING**: 一部がWARNING閾値超過だがNG無し
- **FAIL**: NG閾値を超過するエンドポイントが1件以上
