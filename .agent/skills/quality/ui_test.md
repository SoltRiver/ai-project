# UI Test Skill

品質管理エージェントとして、UIの品質を体系的に検証するスキルです。
ブラウザサブエージェント（`browser_subagent`）を使用して実際の画面を操作・確認します。

## 前提条件
- Uvicorn サーバーが起動していること（`http://127.0.0.1:8000`）
- `browser_subagent` が利用可能であること

---

## 1. 画面レイアウト・構成テスト

画面の構造が設計意図通りであることを検証する。

### チェック項目
| # | 観点 | 確認内容 | 判定基準 |
|---|---|---|---|
| L-1 | ヘッダー/ナビゲーション | 全ページで共通ヘッダーが表示される | ロゴ・ナビリンクが存在 |
| L-2 | フッター | 全ページでフッターが表示される | フッター要素が存在（設計上ある場合） |
| L-3 | セクション順序 | 各ページのセクションが仕様通りの順序で並ぶ | DOM順序が一致 |
| L-4 | 要素の重なり | 要素同士が意図せず重ならない | `overflow: hidden` による切れ落ちがない |
| L-5 | 余白・間隔 | セクション間に適切なマージン/パディングがある | 視覚的に「詰まり」がない |
| L-6 | グリッド/カード整列 | カード型UIが揃って表示される | flex/grid のずれがない |
| L-7 | 空エリア | コンテンツがない場合にEmptyStateが表示される | 空白ではなく案内メッセージ |

### 対象ページ
- `/stocks` — 銘柄一覧
- `/stocks/{code}` — 銘柄詳細（全タブ: chart, fundamental, dividend, shareholder）
- `/glossary` — 用語集
- `/candle-patterns` — ローソク足パターン
- `/indices` — 主要指数

### 実行方法
```
browser_subagent で各ページにアクセスし、スクリーンショットを撮影。
DOMの要素順序とCSSの重なりを目視確認する。
```

## 2. UIテスト（操作・インタラクション）

ユーザー操作が正しく機能することを検証する。

### チェック項目
| # | 観点 | 確認内容 | 判定基準 |
|---|---|---|---|
| U-1 | タブ切り替え | htmxタブが正しく切り替わり、コンテンツがロードされる | HTTP 200 + コンテンツ表示 |
| U-2 | ボタン操作 | 追加/削除ボタンが機能する | 成功フィードバックあり |
| U-3 | フォーム入力 | 検索ボックスに入力すると候補が表示される | オートコンプリート動作 |
| U-4 | リンク遷移 | 銘柄名クリックで詳細ページに遷移する | 正しいURLに遷移 |
| U-5 | ホバー状態 | ボタンやリンクにホバー時の視覚変化がある | cursor: pointer + スタイル変化 |
| U-6 | ローディング表示 | データ取得中にローディング表示がある | htmx-indicator 等 |
| U-7 | エラーハンドリング | サーバーエラー時にユーザー向けメッセージが表示される | 500エラーが直接表示されない |
| U-8 | スクロール動作 | 長いコンテンツが正常にスクロールできる | スクロールが詰まらない |

### テスト手順
1. `/stocks` で銘柄追加・削除操作を試行
2. `/stocks/7203` で全タブ（chart / fundamental / dividend / shareholder）を切り替え
3. 検索ボックスにテキスト入力しオートコンプリート確認
4. チャートインターバル切り替え（日足/週足/月足）確認

## 3. 表示項目テスト

各ページで必要な項目が正しく表示されていることを検証する。

### チェック項目
| # | 観点 | 確認内容 | 判定基準 |
|---|---|---|---|
| D-1 | 必須項目 | ページ仕様で定義された全項目が表示されている | 項目の欠落がない |
| D-2 | データフォーマット | 数値・日付・通貨が正しい形式で表示される | 例: 1,234円、2024/01/15 |
| D-3 | Null/未取得表示 | データが取得できなかった場合「-」で表示される | NoneやNullが直接表示されない |
| D-4 | テキスト切れ | 長いテキストが適切に省略される | overflow による切れ落ちがない |
| D-5 | 画像表示 | 全ての `<img>` が正常にロードされている | `naturalWidth > 0` |
| D-6 | グラフ/チャート | チャートが正しく描画されている | canvas/SVG要素が存在 |
| D-7 | 免責事項 | AI生成コンテンツに免責表示がある | disclaimerテキストの存在 |
| D-8 | 単位・ラベル | 数値に単位（円、%、倍）が付いている | 裸の数値がない |

### 対象ページ別の必須表示項目

#### 銘柄一覧 `/stocks`
- 銘柄コード、銘柄名、業種、現在値、前日比

#### チャートタブ `/stocks/{code}/tab/chart`
- ローソク足チャート、出来高、移動平均線、インターバル切替

#### ファンダメンタル分析 `/stocks/{code}/tab/fundamental`
- BS/PL/CF主要項目、EDINETデータ、インパクトバイアスセクション

#### 配当タブ `/stocks/{code}/tab/dividend`
- 配当履歴テーブル、配当チャート

## 4. レスポンシブテスト（追加提案）

異なるウィンドウサイズでレイアウトが崩れないことを検証する。

### チェック項目
| # | 観点 | 確認内容 | 判定基準 |
|---|---|---|---|
| R-1 | デスクトップ（1920px） | 通常サイズでレイアウト正常 | 要素配置が正しい |
| R-2 | タブレット（768px） | カード/テーブルが折り返す | 横スクロール不要 |
| R-3 | モバイル（375px） | ナビゲーションが適応する | 要素の重なりなし |
| R-4 | 極端に広い（2560px） | コンテンツが中央寄せ/上限幅で収まる | 過度に引き伸ばされない |

### 実行方法
```
browser_subagent でウィンドウサイズを変更し、各サイズでスクリーンショット撮影。
```

---

## 5. アクセシビリティテスト（追加提案）

WCAG準拠の基本的なアクセシビリティを検証する。

### チェック項目
| # | 観点 | 確認内容 | 判定基準 |
|---|---|---|---|
| A-1 | コントラスト比 | テキストと背景のコントラスト比 ≥ 4.5:1（AA） | ダークモードで特に確認 |
| A-2 | alt属性 | 全 `<img>` に意味あるalt属性がある | alt="" も可（装飾画像） |
| A-3 | フォーカス表示 | Tab移動時にフォーカスリングが表示される | outline が見える |
| A-4 | ラベル | 全フォーム要素に `<label>` / `aria-label` がある | 未ラベル入力がない |
| A-5 | 見出し構造 | ページに `<h1>` が1つ、階層が正しい | h1→h2→h3 の順序 |

---

## 6. パフォーマンステスト（追加提案）

ページ表示速度とリソース効率を簡易検証する。

### チェック項目
| # | 観点 | 確認内容 | 判定基準 |
|---|---|---|---|
| P-1 | 初回表示 | ページが3秒以内にレンダリングされる | 体感待ちがない |
| P-2 | タブ切替 | htmxタブ切替が1秒以内に完了する | ローディング待ちが短い |
| P-3 | 画像最適化 | 画像の合計サイズが過大でない | 1MB以上の単一画像なし |
| P-4 | N+1リクエスト | タブ表示で不要な追加リクエストがない | Network監視 |

## 実行フロー（推奨手順）

以下の順序で全テストを実施する。

### Phase 1: 静的チェック（サーバー不要）
1. 全テンプレートHTMLの構造確認（jinja2 include/extends の整合性）
2. CSSファイルの重複/矛盾チェック

### Phase 2: ページ単位テスト（browser_subagent使用）
1. `/stocks` → レイアウト + 表示項目 + 操作テスト
2. `/stocks/7203` → 全タブ切替 + コンテンツ表示確認
3. `/glossary` → カードレイアウト + 画像表示
4. `/candle-patterns` → パターンカード + 画像ロード
5. `/indices` → 指数データ表示

### Phase 3: レスポンシブ + アクセシビリティ
1. 主要ページをウィンドウサイズ変更して確認
2. コントラスト比とフォーカス表示確認

### Phase 4: パフォーマンス
1. ページ表示速度の簡易計測
2. htmxタブ切替の応答速度確認
