# Secrets Management Skill

アプリ内で利用する秘匿情報（APIキー、メール/パスワード、トークン等）を安全に扱うためのスキル。

## 対象
- J-Quants の mail/password（認証情報）
- refreshToken / idToken（アクセストークン）
- 将来的なAPIキー、DB接続情報、外部サービス鍵

## 目的
- ソースへの直書き・誤コミット・ログ漏洩を防ぐ
- デプロイ先（OS / systemd / Docker / PaaS / CI）で安全に参照できる設計に統一
- レビュー観点を固定し、事故率を下げる

## 原則（最重要）
1. **コードに秘密情報を書かない**
2. **クライアント（ブラウザ）へ秘密情報を渡さない**
3. **ログ/例外/HTMLへ秘密情報を出さない**
4. **公開後は“デプロイ先”で環境変数/Secretsを設定して参照する**
5. **トークンは永続保存しない（必要なら期限付き+最小権限+暗号化）**

## Implementation Guide（実装ガイド）
- **環境変数**: `os.environ.get("KEY")` を使用し、`.env` ファイルは `.gitignore` に登録されていることを確認する。
- **ログ**: 認証情報を含むオブジェクトをログ出力しない。フィルタリングを行うこと。

## Checklist
- [ ] 秘密情報がハードコーディングされていないか
- [ ] `.env` ファイルがコミット対象外か
- [ ] ログ出力にトークンやパスワードが含まれていないか
